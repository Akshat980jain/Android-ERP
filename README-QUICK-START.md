# 🚀 ERP System - Quick Start

## Start All Servers with One Click!

### For First Time Setup:
```
Double-click: start-all-servers.bat
```

### For Daily Development:
```
Double-click: start-servers-quick.bat
```

### To Stop All Servers:
```
Double-click: stop-all-servers.bat
```
